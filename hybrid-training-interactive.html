EXTENDED DEMONSTRATION · 200 INDEPENDENT ELEMENT PARAMETERS

The manuscript tunes four regional stiffness parameters. This interactive extension assigns a separate Eᵢ to every cell in a 20 × 10 mesh. Watch all 200 parameters evolve through swarm search and bounded local refinement toward the same target of 500,000.

01 / PARTICLE SWARM OPTIMIZATION

24 candidate fields explore 200 dimensions. Every particle carries a complete vector [E₁, E₂, …, E₂₀₀], and every coordinate is updated from its inertia, personal best, and swarm best.

02 / BOUNDED LOCAL REFINEMENT

The best swarm field initializes a projected limited-memory BFGS demonstration. All 200 parameters are refined together with gradient information, a line search, and bounds.

WHAT IS LEARNING HERE?

All 200 cell parameters are distinct optimization variables. Neighboring elements within the same region can have different initial values and follow different paths. The selected cell’s trace and values update as learning progresses.

pᵢ = Eᵢ / 500,000
J(p) = mean[(pᵢ − 1)²] + 0.04 mean[(pᵢ − pⱼ)²]
0.4 ≤ pᵢ ≤ 1.6

The second term compares neighboring cells. This is a synthetic parameter-fitting objective with a known target, not the manuscript’s FEM/measurement mismatch. No finite-element response, contraction, or inverse identification is solved in this preview.

Based on Mehrdad Shafiei Dizaji’s supplied technical manuscript, A Hybrid Training Algorithm for Continuum Deep Learning Neuro-Skin Neural Network. The manuscript proposes PSO followed by L-BFGS-B. This browser extension runs PSO followed by projected L-BFGS as an educational approximation of bounded local refinement; it is not a full L-BFGS-B implementation or a reproduction of the paper’s numerical study. The element-wise extension is an educational demonstration.
