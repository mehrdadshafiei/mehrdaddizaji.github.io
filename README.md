# Mehrdad Shafiei Dizaji — Academic Portfolio

This folder is ready to publish with GitHub Pages.

## Before publishing

1. Open `index.html`.
2. Replace `YOUR_EMAIL@example.com` with your preferred public email.
3. Replace the placeholder `#` links for:
   - Google Scholar
   - LinkedIn
   - GitHub
4. Your current Word CV is already included as:
   `Mehrdad_Shafiei_Dizaji_CV.docx`

Optional: later you can replace the Word CV with a PDF version if you prefer.

## Publish with GitHub Pages

### Option A — easiest repository name

1. Create a GitHub account if you do not already have one.
2. Create a new PUBLIC repository named:
   `YOURUSERNAME.github.io`
3. Upload:
   - `index.html`
   - `style.css`
   - `Mehrdad_Shafiei_Dizaji_CV.docx`
4. Commit the files.
5. Open repository **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Choose:
   - Branch: `main`
   - Folder: `/ (root)`
8. Save.

Your site should then use the address:

`https://YOURUSERNAME.github.io`
